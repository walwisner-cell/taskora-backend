## What this part of Admin is for

**System Check** tests every part of Trothen at once (the database, file storage, email, payments, calls, maps and more) and shows **green**, **orange** or **red** for each, with the likely cause and what to do.

## Running it

1. Press `Check now`. It takes a few seconds.
2. Read the result:

| Colour | Meaning | What to do |
|---|---|---|
| Green | Working. | Nothing. |
| Orange | Needs attention soon. | Read the cause; plan the fix. |
| Red | Not working now. | Tell whoever fixes it straight away. |

3. Under each orange or red part is the **likely cause** and **what to do**.
4. `Copy report` copies the full result. Send it to whoever fixes it: it has everything they need.

## When to run it

- **Every morning.**
- Whenever someone says something doesn't work ("I can't sign in", "codes don't arrive", "calls don't connect").
- After an update of Trothen.

## Good practice

- Don't guess: send the copied report, not a description from memory.
- A red item that affects money or sign-in (database, email, payments) is urgent: tell a super admin at once.
