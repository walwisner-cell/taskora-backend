## What this part of Admin is for

This page decides **what can be booked** on Trothen (the **service categories**: Plumbing, Cleaning, Tutoring and so on) and **where Trothen is live** (the **countries**).

> **Rule:** Turning a country **live** opens Trothen there for real people. Do it only when Trothen is ready there: payments, prices, the team, and the local rules checked.

Super admins make these changes.

## Service Categories

The list (with a search box) shows, for each category:

| Column | What it shows |
|---|---|
| Category | The name and its icon. |
| Verified Pros | Pros in this category with an approved ID. |
| Customers Can Find | Pros customers can actually find: **ID verified**, **with a profile photo**, offering services (not goods only), and not suspended, closed or on hold. "With no profile photo" counts the pros to remind: without a photo they don't appear in search or get job matches. |
| Offered In | All countries, or only some. |
| Response Window | How long a pro has to answer a job in this category. |
| Active | Whether customers can book it. |
| Action | `Change`, `Save`, `Delete`. |

### Adding a category

Press `+ Add Category`, type the name, choose an **icon**, and save. Use a clear, common name people search for ("Plumbing", not "Pipe Solutions").

### Changing one

- **Offered In:** limit a category to the countries where it is legal and wanted.
- **Response Window:** shorter for urgent trades (a burst pipe), longer for planned work (tutoring).
- **Active:** switch it off to stop new bookings. Bookings in progress continue.

### Deleting one

Delete only a category nobody uses. If pros are in it, move them first, or simply switch it off.

### Licensed trades

Some categories are **licensed trades** (for example electrical work). Pros in them must upload a valid licence, and extra skills in them are checked in **Stores & Skills**.

## Countries

All countries (with a search box), and which are **live**.

- Making a country **live** lets people there sign up and book.
- `+ Add Country` adds one to the list. `Delete` removes one that is not live and has nobody in it.

Before making a country live, check: its **currency** and exchange rate (Plans & Pricing), **payment** options (Tokens → Countries), **Rides** rules and fares if rides will be on, and that someone in the team covers it (Locations & Admins).

## Sync Latest Categories & Countries

`↻ Sync Latest Categories & Countries` adds any categories and countries from Trothen's latest standard list that are missing, and fills in missing icons. It never removes anything. It says "Already up to date" when there is nothing to add. Use it after an update of Trothen.

## Mistakes to avoid

- Making a country live before payments and prices are ready.
- Deleting a category pros are in.
- Category names nobody would search for.
