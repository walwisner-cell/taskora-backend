## What this part of Admin is for

The **Contact Us** form on Trothen's website sends its messages here: questions, complaints, press, partnerships, anything. Each one needs an answer.

> **Rule:** Every message gets a reply, even if it is only to say who will handle it. A message left unanswered is a customer lost.

## The page

- **Total Messages** and **New**.
- **All Messages**: the name, email, subject, city (if given), the message, when it came in, and its **status**.

Set the **status** with the list on each row:

| Status | Meaning |
|---|---|
| New | Nobody has dealt with it yet. |
| Read | Someone is dealing with it. |
| Resolved | Answered and settled. |

## Working a message

1. Read it. What does the person need?
2. Decide who answers:
   - a question about **a booking, a payment or a dispute**: the matching team (and the person should use Report a Problem in the app for a booking);
   - **press, partnerships, investors**: your manager;
   - **a safety concern**: your manager at once.
3. Reply by email, politely, within **1 working day**.
4. Set it to **Read** while you deal with it, and to **Resolved** once it is answered and settled. If they write again, set it back to **New**.

## Good practice

- Never ask for a password, a card number or a PIN. Trothen never needs them.
- Never send personal details of anyone else in a reply.
- If someone says they are in danger, treat it as urgent and tell your manager straight away.

> **Note:** **Job Applications** from the Careers page are in their own list, handled by HR.
